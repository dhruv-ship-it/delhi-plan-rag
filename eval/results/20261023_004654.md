## Which score can decide when to refuse?

Retrieval only, no LLM call, scored under `hybrid+location` (and under `hybrid+location+rerank` for the cross-encoder signal, which only exists there). Each signal is the **top-1** value for the question: the question is refused before any API call when that value falls below `settings.abstain_threshold`.

`fused_score` is here to be rejected rather than used. An RRF score only encodes rank position, so the best chunk for a question about Mumbai property tax scores exactly what the best chunk for a question the gazette answers in full scores. Read its two percentile rows against each other and the point is immediate (D-071).
